# 判断の早見表（INDEX）

使い方：ここで、いまの画面の事実に当てはまる判断（ID）を見つけ、その ID の節だけを本で開く。本は `README.md` の表で決める（◎の本は全部読み、○の本はここから ID 単位で開く）。
開いた判断は設計書の判断の行に ID で出す（開かずに書けない）。「読むのはどんな時」に当てはまる行だけ開く。正はそれぞれの本（重なったときは README.md の表）。
