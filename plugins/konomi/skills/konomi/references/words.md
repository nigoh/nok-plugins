# 文言の理論

画面に出す言葉（呼び名、ボタン、見出し、誤り、空、待ち、完了、補足）を決める表。

読む工程：要件（呼び名）、操作と言葉、ビジュアル・UI 設計（文言の長さ）、実装（置き場所）。早見表は references/INDEX.md。
印：〔調査〕指針で確認／〔原理〕考え方から導出／〔目安〕このスキルの値（実物で直す）／〔試作〕試作で決定。出どころ・検査（WORDS-01〜09）は records/sources.md・records/checks.md、設計書の書式（文言表）は references/design-doc.md。〔目安〕の確かめていない物も records/sources.md。

表に無い場面は原理（LP-）に戻る。型と理由は `L-03：窓の主ボタン・最長 8 字・題が「請求書を取り消しますか」→ 「請求書を取り消す」。副は「やめる」` の形で 1 行残す。好みと食い違えば LP に反しない範囲で好み。

## 原理

| ID | 原理 |
| --- | --- |
| LP-1 | 利用者の言葉で、1 つの物は 1 語〔調査〕 |
| LP-2 | ボタンは押した結果を言う〔調査〕 |
| LP-3 | 誤りは「何が起きたか」と「どう直すか」を言い、責めない〔調査〕 |
| LP-4 | 見える文言と読み上げ名は同じ語を含む〔調査〕 |
| LP-5 | 同じ場面は同じ型で言う〔原理〕（ボタン「〜する」、済んだ知らせ「〜しました」、待ち「〜しています」） |
| LP-6 | 読む量を減らす〔原理〕。1 文に 1 つの事、注意は操作の直前に（D-10） |
| LP-7 | 静かな声で言う〔原理〕。驚かせない、持ち上げない、謝りすぎない |
| LP-8 | 作り手の言葉を画面に出さない〔原理〕。状態名、ID、「空状態」「主役」は読む人の言葉ではない |

## L-01 呼び名の表（terms）：何を 1 語に決めるか

根拠：LP-1・LP-2・I-25。軸：①画面をまたいで出るか ②同じ物の別の言い方が実際にあるか ③お金・期限・取り消しに関わるか ④利用者が自分の書類で使う語か

| 条件 | 決め方 |
| --- | --- |
| 画面名、メニュー、状況の語（下書き・送付済み…） | 必ず 1 語。メニュー・見出し・戻る先は同じ文字列。状況は札の調子（status）と対で書く |
| 2 画面以上に出る名詞（請求書、取引先、明細） | 決める。画面ごとに言い換えない |
| お金・期限・取り消しの動詞（送る、取り消す、記録する） | 決める。何が起きるかを 1 行添える（送る＝番号を付けて相手に出す、1 つの操作） |
| 利用者の語と会計・システムの語が別 | 利用者の語（「入金の確認」を使い、「消込」は避ける）〔試作〕 |
| 制度が名前を決めている（適格請求書） | 制度の語をそのまま。意味は補足に 1 文。avoid に当たる語（適格請求書発行事業者の「事業者」）は terms に `allow: ["適格請求書発行事業者"]` と書いて許す（L-02）〔試作〕 |

## L-02 避ける語（avoid）と、設計の言葉の見分け方

根拠：LP-1・LP-8。軸：①画面のどこに出ても間違いか ②日本語の語か ③設計・開発の内部の語か

| 条件 | 決め方 |
| --- | --- |
| use と同じ意味の別の言い方が実際に使われがち | avoid に入れる（ステータス、顧客、キャンセル） |
| 画面のどこかで正しく使う語 | 入れない。検査は全文字列を見るので、入れると全画面で出せない。制度の語に含まれる語だけは例外で、`allow` に制度の語の全体を書く（screens.yaml の terms に置き、ui-audit と terms.test.ts が同じ許可を読む）〔試作〕 |
| 英字・数字だけの語（invoice） | 入れない。識別子や URL に当たって誤検出する。日本語の語だけを 1 行の配列で書く〔試作〕 |
| 設計の語（状態名 empty・loading、`SCR-`・`REQ-`・`CMP-`、「空状態」「主役」「この図が答える問い」） | 固定の表として常に検査に加える。terms の avoid とは別 |
| 利用者向けか作り手向けか迷う文 | 「はじめて使う人が自分の言葉で言い直せるか」。言えなければ出さない |

## L-03 ボタンの名前

根拠：LP-1・LP-2・LP-5・LP-6・I-16。軸：①押すと何が起きるか ②似た操作が同じ画面にあるか ③同じ幅に何個並ぶか ④題で対象が分かるか

| 条件 | 決め方 |
| --- | --- |
| 通常 | 「対象を＋動詞（辞書形）」：請求書を送る、入金を記録する |
| 題が対象を言っている・対象が 1 つ・軽い操作 | 動詞だけ（保存する、閉じる、やめる）。お金・取り消し・期限に関わる主ボタンは対象つき（L-05） |
| 似た操作が同じ画面に 2 つ以上 | 対象を付ける（「下書きを保存する」）。同じ操作は全画面で同じ文字列 |
| 「OK」「はい」「いいえ」「実行」「確認」だけ | 使わない。結果を言う動詞に〔調査〕 |
| 閉じるだけ／業務として無かったことにする | 前者「やめる」、後者「取り消す」。同じ窓に並べても取り違えない〔試作〕 |
| 長さ（同じ行に並べるボタン） | 3〜9 字〔目安〕（「やめる」「閉じる」は 3 字）。10 字以上は対象を削り、削った意味は窓の本文の項目で言う。「…」で切らない（D-09）。要件が指定していても理論を正に短くし、要件を直す（「差額を手数料として確認する」13 字→「差額を確認する」）〔試作〕 |
| 375px で 2 個を 1 行（3 個なら 5 字まで〔目安〕） | 16px は 8 字、14px は 9 字まで。計算：((375−32−8)÷2−内側の左右 2em)÷文字の幅〔目安〕（D-05） |
| 処理中・文末 | 「〜しています」に替え、幅は変えない（A-01）。「…」・句点・「ください」は付けない |

## L-04 見出しと題名

根拠：LP-1・LP-6・LP-7・W-13。軸：①メニューに出る画面か ②区画の中身は一覧・数字・操作のどれか ③窓か

| 条件 | 決め方 |
| --- | --- |
| 画面の見出し | メニュー・戻る先・ブラウザの題と同じ（terms の画面名） |
| 区画の見出し | 中身の名前の名詞（「入金の状況」）。16 字以内で 1 行〔目安〕。文にしない |
| 末尾 | 句点・「？」「！」なし |

## L-05 確かめの窓の文

根拠：LP-2・LP-3・LP-5・LP-6。軸：①何が起きるか ②取り消せるか ③影響が及ぶ相手・件数（窓を出すかどうかは E-08）

| 条件 | 決め方 |
| --- | --- |
| 題・本文・主ボタン | 同じ動詞（題「請求書を取り消しますか」、主「請求書を取り消す」）。「はい」にしない。L-03 の字数（主ボタンは 9 字以内）と衝突するとき：主ボタンは同じ動詞のまま対象を縮め（「差額を確認する」）、題は名詞や長い言い方でもよい（「請求書番号の付け方」）。縮めて落ちた意味は本文の項目で言う〔試作〕 |
| 離れる確かめの窓 | F-09 が正（主「保存して離れる」、「保存せず離れる」、副「入力に戻る」）〔試作〕 |
| 本文 | 起きること 1 文＋戻せるか 1 文。戻せないなら言い切る。宛先・合計・期限は文でなく項目で並べる（中身は E-08） |
| 「元に戻す」で救える | 窓を出さず、済んだ知らせに「元に戻す」（E-08） |

例：本文「取り消すと、この請求書は取り消し済みになります。元には戻せません。」

## L-06 誤りの文

根拠：LP-3・LP-7・D-09。軸：①誰の誤りか（入力・通信・サービス） ②利用者に直す手段があるか ③欄を特定できるか（I-22）。出す場所は欄ごと F-04、種類と置き場は E-06 が正で、ここは文だけ。

| 条件 | 決め方 |
| --- | --- |
| 欄の誤り | 空は指示（「取引先を選んでください」）、形式は事実＋頼み（「郵便番号は7桁の数字で入力してください」）。入力は消さない。欄と一覧は同じ文〔調査〕 |
| 通信・保存の失敗 | 何ができなかったか＋入力は残っている＋次の一手（「送れませんでした。入力は残っています。もう一度送ってください。」） |
| 使わない語 | 「エラー」「不正」「無効」「正しくありません」、通信コード（500、null）、「サーバー」「例外」〔調査〕 |
| 責める言い方 | 「〜を忘れています」「入力ミス」は使わない。頼む形（「〜してください」） |
| 謝罪 | 入力の誤りでは謝らない。サービス側の失敗でも謝罪語を付けず、事実と次の一手 |
| 長さ | 2 文まで、各 40 字以内〔目安〕。句点を付ける |

## L-07 0 件・初回の文

根拠：LP-2・LP-3・W-10・W-15。軸：①空の理由（まだ作っていない／絞り込み／権限）②次の一手（種類の決め方は E-05）

| 条件 | 決め方 |
| --- | --- |
| 初回（まだ 1 件も無い） | 題「〜はまだありません」＋説明＝何をすればここに並ぶか 1 文＋主ボタン 1 つ |
| 絞り込みで 0 件 | 題「条件に合う〜はありません」＋条件を外す手段。作るボタンは置かない |

例：「請求書はまだありません」／「最初の請求書を作ると、ここに並びます。」／「請求書を作る」。「データがありません」は使わない（LP-8）。

## L-08 待ちと完了の文

根拠：LP-3・LP-5・LP-6・LP-7・N-2。軸：①待ちの長さ ②結果が画面で見えるか ③取り消せるか（出す・出さないは A-03）

| 条件 | 決め方 |
| --- | --- |
| 待ち | 「何を」＋「〜しています」（請求書を送っています）。「…」「お待ちください」は付けない |
| 10 秒を超える | 何をしているかと、やめる手段 |
| 済んだ知らせ | 「対象を＋〜しました」。ボタンと同じ動詞（「保存する」→「保存しました」） |
| 取り消せる | 「元に戻す」を添える（E-08） |
| 長さ | 20 字以内、句点なし〔目安〕。「！」「ありがとうございます」を付けない |

## L-09 補足文・ヒント・入力例

根拠：LP-6・I-01。置き場所・大きさ・常時表示は F-03、操作の直前の注意は D-10 が正。言い方だけ決める。

| 条件 | 決め方 |
| --- | --- |
| 規則（形式・文字数・上限） | 事実を 1 文で。「〜で入力してください」と頼まない（誤りの文と区別） |
| 入力例 | 「例：」で 1 つ。そのまま入れられる値 |

## L-10 文体（敬語の段）と表記

根拠：LP-5・LP-7・taste.md。「静か」の性格：驚かせない、持ち上げない、急かさない。表記の考え方は文化庁の指針〔調査〕。jp-design と食い違えば jp-design が正。

| 条件 | 決め方 |
| --- | --- |
| 文（説明・誤り・知らせ） | です・ます |
| ボタン・見出し・札・ラベル | 言い切り。ボタンは辞書形、見出しは名詞 |
| 頼む | 「〜してください」。入力・選択・やり直しを頼むときだけ。続けて使わない |
| 避ける言い方 | 「〜させていただく」「〜となります」「〜のほうを」「ご利用ください」。主語は省く（「あなた」と言わない）〔原理〕 |
| 感情・記号 | 「！」「…」「？」、絵文字、「簡単に」「ぜひ」を使わない。範囲は「11/1〜11/30」、並列は「・」 |
| ひらく語 | できる、ください、ある・ない（補助）、こと・とき・ため・ほか、さらに。「全て」は「すべて」に決める〔調査〕 |
| 数字・字種 | 算用数字（半角）、桁区切り、「3か所」。カタカナは全角で長音を付ける。全角の数字・英字、半角カナ、数字と日本語の間の空白は使わない〔調査〕〔試作〕 |
| 句点 | 文（説明・誤り・ヒント）に付ける。ボタン・見出し・札・ラベル・表のセル・済んだ知らせ（短い）は付けない〔試作〕 |

## L-11 数・日付・金額・件数を文に入れる

根拠：LP-1・G-05・G-07。書式（桁区切り、円、負の数、日付の形、和暦）は G-05・G-07 が正。ここは文に入れるときの言い方だけ。

| 条件 | 決め方 |
| --- | --- |
| 金額・日付・期間 | 文の中でも G-05・G-07 の形のまま（「万」に丸めない、和暦にしない） |
| 件数 | 「3件」「0件」。数を含む文は対象を先に（請求書を3件送りました） |
| 税 | 税抜・税込を必ず書く |
| 時刻の相対 | 24 時間未満だけ「N分前」。それ以上は日付（G-07） |

## L-12 リンクと読み上げ名

根拠：LP-2・LP-4。

| 条件 | 決め方 |
| --- | --- |
| リンク | 行き先か結果を書く（「請求書の一覧を見る」）。「こちら」「ここ」「詳細」だけにしない。同じ行き先は同じ文言、違う行き先は違う文言〔調査〕 |
| 見える文字のあるボタン | 読み上げ名は見える文字を含める。aria-label で上書きしない〔調査〕 |
| 絵だけのボタン | aria-label に動詞＋対象（「知らせを閉じる」）。窓の「閉じる」のように対象が明らかなら動詞だけ |

## L-13 文言の置き場所と変えやすさ

根拠：LP-6・T-3・T-6・M-21・S-04。軸：①全画面で同じでなければならないか ②テストが同じ文字列を引くか ③画面にしか出ないか

| 条件 | 決め方 |
| --- | --- |
| 画面名、メニュー、状況の語、ボタンの動詞。欄のラベルや列の見出しがこれらと同じ語（例：取引先）のときも | 1 か所（terms.ts と screens.yaml の terms は同じ内容）。画面は引く。直書きしない |
| 画面にしか出ない文（題、説明、空の文） | 画面の文言ファイル `copy.ts` に集める（画面ごとに 1 つ）。連結せず差し込む（M-21）〔試作〕 |
| 状況の語と札の調子 | 対で 1 か所（status.ts）。部品は調子だけ受ける |
