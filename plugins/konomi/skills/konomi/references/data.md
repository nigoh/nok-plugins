# データの見せ方の理論

数字・表・図を、どの形で、どの書き方で見せるかを決める表。図の置き方・文字の大きさ・凡例・組み替えは decisions.md の D-12・D-13 と laws/visual.md の V-27〜V-35 が正で、ここでは ID で指す。

読む工程：ビジュアル・UI 設計、操作と言葉、テスト。早見表は references/INDEX.md。
印：〔調査〕指針で確認／〔原理〕法則から導出／〔目安〕このスキルの値（実物で直す）／〔試作〕試作の気づき。出どころ・検査（DAT-01〜09）は records/sources.md・records/checks.md、設計書の書式は references/design-doc.md。〔目安〕の確かめていない物も records/sources.md。

無い組み合わせは原理（GP-）に戻る。理由は `G-04：入金 12 件・金額を 1 円まで照らす → 表。金額は右揃え、単位は見出し` の形で 1 行残す。好みと食い違えば GP に反しない範囲で好み。

## 原理

| ID | 原理 |
| --- | --- |
| GP-1 | 数字は比べる相手があって読める〔原理〕 |
| GP-2 | 長さと位置で比べる形が最も読み取りやすい〔調査〕。棒が既定、円は割合を数字でも書くときだけ |
| GP-3 | 図は 1 つの主張と、題・1 文の要約を持つ〔調査〕 |
| GP-4 | 桁がそろえば比べられる〔調査〕。数の列は右揃え・等幅・同じ小数の桁、単位は 1 か所 |
| GP-5 | 0・データなし・まだ変わる、は別のもの（「0円」は計算してゼロ、「—」は無い、「途中」はまだ変わる） |
| GP-6 | 丸めは読みやすさのため。請求・入金・差額は丸めず、図の目盛りだけ丸める |
| GP-7 | 同じ数字は、どこで見ても同じ値。画面・表・図・書き出しは 1 つの集計から（T-3） |
| GP-8 | 色と図だけで伝えない〔調査〕。文・数字・表でも同じ内容が得られる（V-11・V-31） |

## G-01 数字 1 つか、表か、図か

軸：①値の個数 ②正確な値（1 円まで）が要るか ③形（増減・大小）が主役か

| 条件 | 選ぶもの |
| --- | --- |
| 値が 1 つ、比べる相手が 0〜1 つ | 大きな数字（G-03）。1 画面 3 つまで〔目安〕 |
| 値が 2〜4 個で並べるだけ、または時間の点が 4 つ以下 | 同じ書式で並べた数字。図にしない |
| 同じ項目を 4 行以上、正確な値で照らす・突き合わせる | 表（D-11・G-04） |
| 時間の点 5 つ以上、または比べる項目 5 個以上で、形が主役 | 図（G-02）＋要約と表（G-11） |
| 主張が無く、データを見せるだけ | 表か一覧。図にしない〔調査〕 |

## G-02 図の種類

軸：①問い ②点・項目の数 ③名前の長さ

| 問い・条件 | 選ぶもの |
| --- | --- |
| 比べる・項目 5 個以上、または名前が全角 12 字超 | 横棒。長さ順。名前は折り返して全部見せる（D-09）〔調査：棒〕 |
| 移り変わり・各点が「その月の合計」・5〜12 点 | 縦棒（0 始まり）。2 系列は並べる〔調査：合計は棒〕 |
| 移り変わり・連続した量や率、または 13 点以上 | 折れ線。点に印。データなしで線を切る〔調査：推移は線〕 |
| 内訳・項目 4 個以上 | 棒か、表の「割合（%）」の列 |
| 内訳・項目 2〜3 個で合計 100%、「半分を超えるか」を知る、割合を数字で直接書く | 円グラフを使ってよい。それ以外は使わない〔目安〕 |
| 分布（支払までの日数）・関係（2 つの量）で 30 件以上 | 度数の棒（階級 5〜10）／点の図〔調査〕。30 件未満は表〔目安〕。つづり請求では使わない |
| 達成度（回収率） | 数字「回収済み64%」＋目標を目盛りにした細い棒。メーター・半円にしない |

積み上げ棒、立体・影、左右別の縦軸（2 本）は使わない〔原理〕。

## G-03 大きな数字（指標）

根拠：GP-1・C-06。軸：①何を決める数字か ②比べる相手 ③良し悪しの基準が設定にあるか

| 条件 | 決め方 |
| --- | --- |
| 構成と大きさ | 名前→数字→比べる相手 1 つ。全桁（万円にしない）。display は主役 1 つ、ほかは title。1 行に収まらなければ縦（D-05・D-14） |
| 比べる相手 | 月の途中は先月の「同じ日まで」と文字で書く。月全体と比べない。終わった月・期間全体は直前の同じ長さ（季節の波が大きく 1 年ぶん以上あれば前年同月を足す） |
| 相手のデータが無い・先月が 0 | % を出さない。「先月の記録がありません」「先月は0円」 |
| 残高（時点の量）と期間の合計を並べる | 種類が違うので差・率を出さない。名前に時点か期間を書く（「11月13日時点の未入金」）。同じ書式・単位・位置で隣に置く。比べるのは同じ種類だけ〔原理〕 |
| 前月比 | 差と率を併記「+120,000円（+10%）」＋矢印。14px 以上、`muted`（判断に使う値は 12px にしない、D-06） |
| 良し悪しの色 | 数字に色を付けない（`fg`、補足は `muted`）。基準が設定・契約にあるときだけ（期限を過ぎた請求書が 1 件以上など）隣に `warn` の札と言葉。増減だけで `ok`・`bad` を付けない。増えると悪い数字（未入金）は件数と最古の期限を隣に（V-11） |

数え上げる動きは付けない。例：`G-03：ホームの「今月の請求額」・月の 13 日・先月の記録あり → 「先月の13日までと比べて +120,000円（+10%）」。数字に色なし`

## G-04 表の列・行・並べ替え

軸：①列数 ②数の列 ③行数 ④人が最初に探すもの

| 条件 | 決め方 |
| --- | --- |
| 列の順 | 探すもの（取引先名・請求番号）→状況→日付→金額（右端）〔目安〕 |
| 数の列 | 見出しも数も右揃え、等幅、小数の桁を同じに。「円」は見出し「金額（円）」へ〔調査：右揃え〕。文字の列は左揃え。`th`＋`scope`、表に読み上げ名〔調査〕 |
| 合計行 | 足せる列だけ、最後に「合計」。税込・税抜を書く。20 行を超えてページ送り〔目安〕なら、合計は「条件に合う全件」で、表の上に「全34件・合計4,120,000円」 |
| 並べ替え | 既定は意味のある順（請求書は支払期限が近い順、入金は新しい順、取引先は読み仮名順）。いまの並びを文字で出す。並べ替えの列は 3 つまで〔目安〕、`aria-sort`〔調査〕 |
| 列が 6 つ以上〔目安〕、または最小の列幅の合計が枠を超える | 優先順位を決め、上位 3〜4 列を行の頭に。残りは行をひらいた中（D-13・V-25） |

## G-05 数の書き方

| 対象 | 決め方 |
| --- | --- |
| 数字の字 | 半角。桁区切りは 4 桁以上の金額・件数に半角カンマ。年・番号・郵便番号には付けない |
| 円 | 文・大きな数字は数字の直後に「円」（離さない、D-09）。表の列は見出しへ。`¥` は使わない。請求・入金・差額・合計は 1 円まで、丸めない（GP-6） |
| 図の目盛りの丸め | 最大が 1,000,000円 以上〔目安〕なら「万円」にし、題に 1 回だけ単位（「0・50・100・150」＋「万円」）。1 画面で円と万円を混ぜない。億は 1 億円以上だけ〔目安〕 |
| 小数・率 | 円は小数なし。率は 0 桁。同じ列・同じ図は同じ桁。数字と「%」を離さない。例外：操作の説明の例（「例：100.5円と入れると丸められます」）だけ小数の円を書いてよい。請求・入金・差額の実データには使わない〔試作〕 |
| 負の数 | 「−1,200円」（U+2212）。ハイフンにしない（欠損の「—」と見間違える）。赤にしない。△・括弧にしない（取引先が求める書類だけ例外）〔目安〕 |
| 差額の向き | 向きを 1 つに決めて画面に書き、言葉を添える「550円不足」。0 以外に「+」 |

整形は `src/lib/format` の 1 か所（M-20。ui と data の両方から使う）。`Intl` の出力は負の符号が半角ハイフンなので、その 1 か所で U+2212 に替える〔試作〕。

## G-06 0・データなし・まだ変わる

| 状況 | 書き方 |
| --- | --- |
| 計算できて 0 | 「0円」「0件」。図は高さ 0 の棒に「0」 |
| 取れていない・無い・未入力 | 「—」。読み上げは隠し文字で「データなし」。図は棒を描かず軸に「—」。折れ線はそこで切る（0 に落とさない） |
| まだ変わる（当月） | 「11月（途中）」。棒は斜線か枠だけで確定と分ける。色だけにしない |
| 平均・合計に欠けがある | 欠けを 0 とみなさない。「5か月中4か月ぶん」 |
| 0 件の期間 | 期間も条件なので `filtered_empty`（E-05）。文は L-07。図は軸を残し、図の領域に同じ文を置く（REQ-008） |

コードで欠損を `?? 0` で 0 にしない。型で「無い」を持つ（T-7）。

## G-07 日付と期間

軸：①過去か未来か ②その日付で何を決めるか ③年をまたぐか

| 条件 | 決め方 |
| --- | --- |
| 形 | 詳細・文は「2026年11月13日」、一覧は「11/13(金)」（REQ-003）。同じ列に今年以外が 1 件でもあれば全行を長い形に |
| 期限・請求日・入金日 | 絶対の日付が主。補足に相対を小さく「あと3日」「3日超過」（14px、`muted`） |
| 履歴・更新時刻 | 24 時間未満は「N分前」「N時間前」、以上は「11/12(木) 15:20」。60 秒未満は「たったいま」〔目安〕 |
| 期間 | 同じ年は年を 1 回「2026年5月〜10月」。「月」「年」「日」を付けるのは整形の関数 1 か所だけ（呼ぶ側は足さない。「6月月」「11日日」を防ぐ）。またぐ「2026年11月〜2027年4月」。図の月の目盛りも、年が変わる月だけ「2027年1月」〔目安〕 |
| 年度・和暦 | 年度は「2026年度（2026年4月〜2027年3月）」と期間を併記。画面は西暦。和暦は取引先が求める書類（請求書 PDF の日付欄）だけ、設定の 1 か所。「令和8年11月13日」〔目安〕 |

## G-08 軸とラベル

| 条件 | 決め方 |
| --- | --- |
| 棒 | 0 から始める。切らない（REQ-023）〔調査〕 |
| 折れ線 | 最小が最大の 1/2 未満なら 0 から。1/2 以上は 0 を外してよいが「縦軸は0から始まっていません」と図のそばに書く〔目安〕 |
| 目盛り | 3〜6 本〔目安〕。刻みは 1・2・5 の 10 のべき（0・50・100・150）〔調査：なじみのある数列〕。上端は最大値の次の刻み。単位は題に 1 回。期間を切り替えて上限が変わるなら「縦軸が変わりました」と 1 文〔原理〕 |
| ラベルの間引き | ラベルの間が 8px 未満なら 1 つおき〔目安〕。最初・最後・現在の月は必ず出す。間引いた棒の値は表に任せる |

## G-09 凡例・系列の数

軸：①系列（1 つの図に重ねる線・並べる棒の組）の数 ②名前の長さ。1 本の棒に並ぶ項目（取引先別）は G-10。系列の色と手がかりは C-11 が正で、ここは数とまとめ方だけ。

| 条件 | 決め方 |
| --- | --- |
| 系列 1 つ | 凡例なし。題に書く |
| 2〜4 つ | 線の端か最初の棒の上に名前を直接書く。収まらないときだけ図に接した 1 行の凡例（D-12・V-28）。色は C-11 |
| 5 つ以上 | 上位 4 つ＋「その他」〔目安〕。色は「その他」を含め 5 つまで（C-11） |
| 「その他」 | 最後に置く。「その他（9社）」と件数。1 位より大きくなったら上位を 7 つまで増やす〔目安〕。図は上位だけ、同じ画面の表は全件 |

## G-10 期間の切り替えと、データの量

| 条件 | 決め方 |
| --- | --- |
| 期間の選択肢 | 2〜5 個ならセグメント（D-02。半年・1 年・今年度）。既定は直近の半年〔目安〕。URL に持つ（REQ-027） |
| 切り替えと表示 | 図・表・大きな数字・書き出しの全部が同じ期間に。図の題の下に常に「2026年5月〜10月（6か月）」。待つ間は骨組み（A-03）。最後の月が当月なら「途中」（G-06） |
| 縦棒が 13 点以上／横棒が 11 項目以上／表が 21 行以上〔目安〕。0 件は E-05、点が 1〜4 は G-01 | 四半期にするか期間を絞る／上位 10＋「その他」と全件の表／ページ送り（件数を表の上に）。棒を細くして詰めない |

## G-11 図の代わりの文と表、狭い幅

| 条件 | 決め方 |
| --- | --- |
| 表が要件の主役（取引先別の内訳の全件を見る、など）で、要件が内訳の表を必ず見せると決めている | 要件を正にする：13 行以上でも畳まず常に見せる（20 行超はページ送り、G-04）。畳んでよいのは図の補助の表だけ。理論の例外として、設計書にその REQ の ID を書く〔試作〕 |
| すべての図 | 題（知りたいことの名前）＋ 1 文の要約。数字を入れ、評価の語（「大きく」「徐々に」）を使わない：「10月の請求額は1,280,000円で、9月より120,000円多い」〔調査〕 |
| 読み上げと表 | 図に `role="img"` と要約と同じ名前。同じ数字の表を図の直下に：12 行以下は常に見せ、13 行以上は「数字で見る」で開く〔目安〕（閉じても要約は残る、V-17）〔調査〕 |

同じ内容が文字か表にあれば、図の線・境の 3:1 は免除。図の中の文字は 4.5:1〔調査〕。

## G-12 書き出しと画面の一致

| 条件 | 決め方 |
| --- | --- |
| 作り方と範囲 | 同じ集計関数から、整形だけ分ける（GP-7）。画面に出ている条件のまま（絞り込み・期間・並び）。ボタンの近くに「この12件を書き出す」 |
| 数 | カンマ・「円」・「万」なしの数字。見出しに単位「金額（円）」。負は「-1200」（書き出しだけ半角ハイフン。画面は G-05）。丸めた値を持ち込まない〔目安〕 |
| 日付・欠損 | 「2026-11-13」。欠損は空欄（0 にしない）。途中の月は列「確定」に「途中」 |
| 文字・名前 | UTF-8（BOM つき）。日本語版の表計算で文字化けしない〔目安〕。名前に条件「つづり請求_売上レポート_2026-05_2026-10.csv」 |
