# 動きの理論

押し心地・待ち時間・視線の導き方・らしさを、役割と数値で決めるための表。読む工程：ビジュアル・UI 設計、操作と言葉（動きを付ける・外す・速さを決めるとき）。

調査日：2026-11-14。印の意味は decisions.md と同じ（〔調査〕〔原理〕〔目安〕〔試作〕）。出どころ・検査・記録の例は records/sources.md・records/checks.md。

早見表は references/INDEX.md。

## 動きの 5 つの役割

付ける前にどの役割かを言う。どれにも当たらない動きは付けない。

| 役割 | 何を伝えるか | 例 |
| --- | --- | --- |
| 応答 | 操作が受け取られた | 押したボタンが沈む、スイッチが動く |
| 手がかり | 押せる・動かせる・続きがある | 押せる形、端の見切れ、開閉の印の向き |
| 待ち | 止まっていない、あとどれくらいか | 進みの棒、骨組み |
| 誘導 | いま変わったのはここ、次はここ | 足した行が一瞬色づく、開いた所から広がる |
| らしさ | この製品の性格 | 完了の小さな動き、全体の速さとなめらかさ |

対応：応答＝A-01・A-07／手がかり＝A-02／待ち＝A-03／誘導＝A-04／らしさ＝A-06。A-05 は動きを外す条件、A-08 は書き方と検査。

## 原理

| ID | 原理 |
| --- | --- |
| N-1 | 動きは役割を持つときだけ（飾りの動きは 100 回目には邪魔） |
| N-2 | 0.1 秒・1 秒・10 秒（0.1 秒以内は「自分がやった」、1 秒までは考えが途切れない、10 秒超で注意が離れる）〔調査〕 |
| N-3 | 短いほうがよい（ほとんどの動きは 100〜500ms、ここでは 400ms 上限。長すぎる失敗のほうが多い）〔調査〕 |
| N-4 | 入るものは減速して止まり、出るものは加速して去る。出るほうを短く（入るのは読ませ、出るのは待たせない）〔調査〕 |
| N-5 | 動かす主役は位置・大きさ（`transform`）と濃さ（`opacity`）。色・影の小さな変化は可。幅・高さ・余白は避ける（まわりが押されてがたつく） |
| N-6 | 同時に動く主役は 1 つ（2 つ動けばどちらも見られない） |
| N-7 | 動きが無くても意味が欠けない（動きを減らす設定の人・読み上げの人にも同じ情報が届く） |
| N-8 | よく使う操作ほど、動きを小さく短く（1 日に何十回の操作を毎回 0.3 秒待たせない） |

## 時間とイージングのトークン

| トークン | 値 | 使う所 |
| --- | --- | --- |
| `--dur-instant` | 100ms | 押した応答、チェック、スイッチ、乗せたときの色〔調査〕 |
| `--dur-quick` | 150ms | 小さな部品の出入り（札、ツールチップ、メニュー） |
| `--dur-base` | 250ms | 面の出入り（窓、引き出し、開閉）〔調査：200〜300ms〕 |
| `--dur-slow` | 400ms | 画面をまたぐ大きな移動だけ。動きの長さの上限〔調査〕。A-04 の色の余韻のような「保つ時間」は別 |
| `--dur-spin` | 1200ms | 回り続ける動きの 1 周（処理中のボタン、待ちの印）。上限 400ms の対象外。動きを減らす設定では 0ms〔目安〕 |
| `--delay-wait` | 300ms | 骨組み・待ちの印を出すまでの待ち（A-03 の 0.3〜0.5 秒）〔目安〕 |
| `--ease-enter` | `cubic-bezier(0, 0, 0.2, 1)` | 入る・現れる（減速） |
| `--ease-exit` | `cubic-bezier(0.4, 0, 1, 1)` | 出る・消える（加速） |
| `--ease-move` | `cubic-bezier(0.4, 0, 0.2, 1)` | 画面の中での移動・変形 |

- 時間もイージングもトークンで書く。直書きしない。出るときは入るときより 1 段短いトークン。
- `prefers-reduced-motion: reduce` は「大きな動きを減らせ」。移動・拡大縮小・視差・回り続ける動きをやめ、濃さか即時の切り替えに。情報を運ぶ小さな変化（色など）は残してよい。
- 曲線の値は〔目安〕。好みの既定は「静か」：跳ねない、行き過ぎない。

## A-01 ボタンの応答

根拠：N-2・N-5・N-7・N-8（役割：応答・手がかり・待ち・誘導）。問い：乗せたとき・押したとき・待つとき・終わったときに、どう見えるか。

| 状態 | 決め方 |
| --- | --- |
| 何もしていない | 押せると分かる形（塗りか枠）。押す範囲は 24px 以上（WCAG 2.5.8）、目安 44px〔目安〕 |
| 乗せた | 色を 1 段変える。`--dur-instant`。動かさない、大きくしない。`@media (hover: hover)` の中だけ（タッチで色が残らない） |
| キーボードで選んだ | `:focus-visible` ではっきりした輪（地との対比 3:1 以上、WCAG 1.4.11）。動かさない。乗せたときと同じにしない |
| 押している | 押した瞬間に変える（待たせない）。色を 1 段濃く、または 2% ほど縮める〔目安〕。**乗せたときとは別の見た目**（同じ色だと押したと分からない）。縮みは `transform` に出る書き方で（個別の `scale` は検査が読めない）。戻りは `--dur-quick`〔試作〕 |
| 押せない | 薄く（読める濃さで）。理由を近くに書く |
| 処理中 | 幅を変えず、文言を「〜しています」にし、回る印を添える。二重送信を防ぐ（`disabled` は選択が外れるので `aria-disabled`〔要確認〕） |
| 終わった | その場で結果を示す（文言か印）。離れた場所の知らせだけにしない |

- 押した応答は 0.1 秒以内に見えること。通信の返事を待ってから見た目を変えない。〔調査〕
- 状態が変わっても、ボタンの幅と高さを変えない（まわりが動く）。

## A-02 手がかり

根拠：N-1・N-7（役割：手がかり・応答・誘導）。問い：押せる・動かせる・続きがあることは、触る前に分かるか。

| 条件 | 決め方 |
| --- | --- |
| 押せる物 | 静止した状態で押せる形に。タッチの端末には「乗せる」が無い |
| 押せないのに押せそうな物（色のついた見出し、下線、枠で囲んだ文字） | 押せる物と同じ見た目にしない |
| 横に送れる並び | 端の 1 つを見切れさせる。全部が収まって見える幅にしない |
| つかんで動かせる物 | つかむ印を付け、つかんだ瞬間に持ち上げる（影）。ドラッグ以外の手段（キーボード、ボタン）も置く（WCAG 2.5.7） |
| 開閉できる物 | 向きの変わる印。印は動いてよい、`--dur-quick` |
| 初めての人に気づかせたい | 最初の 1 回だけ小さく動かす。くり返さない |

## A-03 待ち時間

根拠：N-2。

| かかる時間 | 見せ方 |
| --- | --- |
| 0.1 秒以内 | 出さない〔調査〕 |
| 0.1〜1 秒 | 押した応答だけ。表示は 0.3〜0.5 秒待ってから、出したら最低 0.5 秒保つ（一瞬だけ出るとちらつく）〔目安〕 |
| 1〜10 秒・形が予想できる（一覧、記事、カード） | 骨組み。実際の配置と同じ形、届いたら入れ替え〔調査〕 |
| 2〜10 秒・形が予想できない、または部品の中の小さな待ち | 回る印と何をしているかの言葉。1〜2 秒は押した応答のまま〔調査〕〔要確認〕 |
| 10 秒超 | 本物の進み（割合か段階）・説明・やめる手段〔調査〕 |
| 取り消せる軽い操作（いいね、並べ替え、チェック） | 先に結果、裏で送る。失敗したら戻して知らせる。**お金・番号・期限に関わらない物だけ**（入金の記録・請求書の送付は当てはまらない。E-08） |

- 進みは本物だけ（偽の棒・止まったり戻る棒は、何も出さないより信頼を損なう）。骨組みは「形が予想できる全画面の読み込み」だけ（効果は調査が割れている）。待つ間に止めるのは押したボタンだけ。
- 回る印は処理中のボタンと、画面に 1 つの待ちの印だけ。札・表・一覧の行の中では使わない（札は止めた絵。C-04）。
- 読み込みは `role="status"` に言葉を入れて読み上げにも伝える。`aria-busy` は対応にばらつき〔要確認〕。割合のある棒は `role="progressbar"`。

## A-04 視線を導く

根拠：N-1・N-3・N-4・N-6・N-7・P-7（役割：誘導）。

| 条件 | 決め方 |
| --- | --- |
| 操作の結果、離れた所が変わった（一覧に行が足された、合計が変わった） | 変わった所を 1 回だけ薄く色づけ、1〜2 秒で戻す〔目安〕。足した行だけ濃さ 0→1（`--dur-quick`）でもよい。全部の行に毎回掛けない（下の「土台の部品が持つ動き」） |
| 画面を開いたとき | 動かしてよいのは主役 1 つまで。全部の区画を順に浮かび上がらせない |
| 複数を順に出す | ずらすのは 1 つ 30〜50ms、全体で 300ms 以内〔目安〕 |
| 新しく現れる物（窓、メニュー） | 出どころ（押した所）から現れ、そこへ戻る |
| 進む・戻る | 向きを対にし、全画面でそろえる |
| 画面の切り替え | 同じ階層は濃さの切り替えだけ。深く入るときは押した所から広がり、戻るときは同じ所へ。`--dur-base` |
| 注意を引きたい | 動かし続けない。点滅・揺れ・鼓動のくり返しを使わない。1 秒に 3 回を超える点滅は禁止（WCAG 2.3.1） |

## 土台の部品が持つ動き（画面で作らない）

ボタン・スイッチ・処理中の印（A-01・A-03・A-07）に加え、次も土台の部品に入れて渡す。画面側で作ると画面ごとにずれ、道具が無ければ動きを省く〔試作〕。

| 部品 | 持つ動き | 値 |
| --- | --- | --- |
| 足した行・変わった所（一度だけ印を付ける口） | 足した 1 行だけ濃さ 0→1、または薄い色づけ 1〜2 秒。一覧の全行・再描画では掛けない | `--dur-quick` |
| 窓・メニュー・引き出し | 出どころから現れ、戻る。出るのは入るより 1 段短く | `--dur-base`・`--dur-quick` |

## A-05 動かさない判断

根拠：N-1・N-6・N-7・N-8

| 条件 | 決め方 |
| --- | --- |
| 1 日に何度も行う操作（保存、一覧の絞り込み、タブの切り替え） | 動きを付けないか、`--dur-instant` まで |
| 誤りを知らせる | 揺らさない。色と言葉と印で知らせ、誤りの欄へ移る |
| スクロールに合わせた動き（視差、スクロールで勝手に進む） | 使わない。固定の見出しは可 |
| 自動で始まり 5 秒を超えて続く動き | 止める手段を付ける。付けられないなら使わない〔調査：要確認〕 |
| 文字を読んでいる最中の、まわりの動き | 止める |

## A-06 らしさ（ブランドの体験）

根拠：N-1・N-6・N-8・T-6。問い：この製品らしい動きを、どこに、どれだけ置くか。

| 条件 | 決め方 |
| --- | --- |
| 全体の性格 | 言葉で 1 つ決め、時間とイージングのトークンに写す（静か＝短め・跳ねない／元気＝少し長め・少し行き過ぎる） |
| 印になる動き | 1 つだけ。置く場所は、うれしい瞬間（完了、達成）か製品の印（ロゴ、主ボタン） |
| それ以外 | 全部、役割だけの静かな動き。印になる動きを引き立てる |
| 頻度 | 印になる動きは、よく通る所に置かない（毎回見せられると邪魔） |
| 製品ごとの違い | トークンと印になる動きを、リポジトリの `.konomi/DESIGN.md` に書く。共通の既定は「静か」 |

- 例：pipe-in の「プラグがカチッとはまる」が印になる動き。pipe-in のリポジトリに書き、ほかの製品に持ち込まない。

## A-07 ボタン以外の部品の応答

根拠：N-1・N-2・N-5・N-6・N-7（役割：応答・誘導・手がかり）。問い：操作の受け取りをどう見せるか。

| 部品 | 決め方 |
| --- | --- |
| スイッチ・チェック | 押した瞬間に状態を変える。つまみは `--dur-instant`〜`--dur-quick`。色だけでなく形（位置、印）でも分ける |
| 入力欄 | 選ぶと枠の色を変える（`--dur-instant`）。動かさない。誤りは近くに言葉で（A-05） |
| タブ・選択 | 選んだ物の下線は、切り替え先へ `--ease-move` で滑らせてよい。中身は濃さだけ |
| 開閉 | 印の向きを変える（A-02）。中身は N-5 に従う |
| 触覚・音 | 既定では使わない。振動は iOS の Safari で使えない〔要確認〕。音は A-06 の印になる動きに限る |

## A-08 動きの書き方と検査

根拠：N-1・N-6・N-7。問い：動きを確かめられる形で書けているか。

| 条件 | 決め方 |
| --- | --- |
| 動きを仕様に書く | 「何が・どこから・どこへ・何ms・どの曲線・どの役割」の 1 行。例：`確認の窓／押した所から中央へ／--dur-base／--ease-enter／誘導` |
| 検査 | 動きを減らす設定で見る。キーボードだけで見る。CPU を絞る。録画をコマ送りし、同時に動く主役を数える |

〔目安〕の数値は一次情報で未確認。実物で外れたら直す。
