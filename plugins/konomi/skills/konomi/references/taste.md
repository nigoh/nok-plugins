# DESIGN.md（好みの既定値）

`~/.claude/konomi/DESIGN.md` のひな形。リポジトリごとに変えたい項目だけを `.konomi/DESIGN.md` に同じ見出しで書くと上書きされる。

骨組み（色を役の名前で呼ぶ、明暗の組、状態の決まり、言葉づかい、角と影の段）は pipe-in のデザインシステムから借り、値は好み診断の結果。pipe-in の色（コーラルとティール）や作業台の決まりは pipe-in 側の `.konomi/DESIGN.md` に置き、ここには入れない。「決定」は本人が選んだ物、「仮」は仮に置いた値。

早見表は references/INDEX.md。

## 方向

- 余白があり、シンプルで、伝わりやすいこと。無駄な装飾は置かない。（決定）
- 好きな方向：和モダン、ナチュラルミニマル、エディトリアル。（決定）
- 避ける方向：レトロ昭和、ネオブルータリズム、ポップ。（決定）

- 表の文字と地の組は、どちらの画面でも 4.5:1 以上を計算で確認済み（`disabled-fg` と `line` を除く）。値を変えたら測り直す。

## 状態は色だけで伝えない

状況の絵と色は color-state.md C-04（規則は C-01・C-02・C-05）。形と言葉を必ず添える。

## 文字

- 見出しも本文もゴシック体。明朝は使わない。（見出しは決定、本文は仮）
- 大小の差は控えめにし、太さと余白で強弱を付ける。（決定）
- 本文の大きさは画面の種類で分ける。（決定）
  - 読み物・サイト・フォーム：本文 16px、行の高さは jp-design に従う。
  - 業務画面・ボードなど密度の高い画面：本文 14px、行の高さ 1.6。入力欄の文字は 16px（iOS の拡大を防ぐ）。
- 段：display 28〜32 / title 22 / heading 16〜18 / body 16 か 14 / small 12〜13。display は 1 画面に 1 つ（ホームの指標は主役 1 つだけ display、残りは title。G-03）。密度の高い画面の見出しも 16px 太字（本文 14px との差は 2px と太さ）。（仮）
- small（12〜13px）は時刻・件数などの補足だけ。入力に必要な例や規則は 14px 以上。（試作で決定）
- 太さは 400 と 700 の 2 段を基本に。（仮）
- 番号・金額・時刻は等幅の数字（`font-variant-numeric: tabular-nums`）。
- 図の中の文字：ラベル 14px 以上、目盛り・補足 12px 以上。収まらないラベルは図の外へ。図を縮めて文字を小さくしない。（試作で決定）
- フォントスタック、禁則、文字詰めは jp-design に従う。書体名は案件ごとに決める。

## 間隔

- 標準とたっぷりの中間。（決定）
- 刻み：`space-4`・`space-8`・`space-12`・`space-16`・`space-24`・`space-32`・`space-48`・`space-80`。並びは flex か grid の gap で空ける。
- 3 段：部品の内側（16〜24）＜ 部品どうしの間（32〜48）＜ セクションの間（パソコン幅 80 以上、スマホ幅 48）。密度の高い画面は一段ずつ詰める。（幅ごとの値は試作で決定）

## 角・影

- 角丸：札 `radius-tag` 6、ボタン・入力 `radius-control` 8、カード・面 `radius-card` 12、大きな面 `radius-panel` 16、チップ `radius-chip` 999。カードの 12 は決定、ほかは仮。
- カードは線で囲まず影で浮かせる。（決定）`shadow-card`：明 `0 4px 24px rgba(31, 35, 40, .06)`、暗は影なしで `panel` と `bg` の明るさの差。（値は仮）`shadow-lift`：明 `0 12px 32px rgba(31, 35, 40, .16)`、暗 `0 12px 32px rgba(0, 0, 0, .55)`。引いているカード・窓・短い知らせだけ。
- カードにするのは「独立して選ぶ・動かす・開く 1 つの単位」だけ。一覧の行・業務画面の区画・フォームの節は余白と線で分ける。選んだ状態は `ai-soft` の地に 1px の `ai`。太い枠は使わない。全部のカードに同じ影を付けない。（試作で決定）
- ボタンは最小の高さと上下の余白で作り、折り返したら縦に伸びる。スマホ幅は見た目も 44px 以上。パソコン幅の密度の高い画面は見た目 36px でよく、当たり判定は 44px 以上（`::after` を `position:absolute; inset:-4px 0`）。一覧の行の中のリンク・アイコンのボタンも同じ。`input` 類は F-12。（試作で決定）

## 基本の部品

動き・言葉づかいの正：motion.md A-01・A-06（性格は「静か」）、words.md L-03・L-06・L-10・L-11、書式は data.md G-05・G-07。好みは「平易な日本語、ふだんの言葉」だけ。

pipe-in の 4 部品を骨組みに、値は上のトークンで置き換える。

| 部品 | 決まり |
| --- | --- |
| ボタン | 主（`ai` で塗る、1 画面に 1 つ）／ふつう（`panel` に枠）／消す（`bad` の枠と文字）／押せない |
| チップ | 絞り込みや選択。選んだものは `ai` で塗るか `ai-soft` の地 |
| 状態の札 | color-state.md C-04 のとおり、アイコンと言葉を添える |
| 知らせ | 案内（ai-soft）／注意（warn-soft）／失敗（bad-soft）／完了（ok-soft）。下に出る短い知らせは地と逆の明るさ |

## 使わないもの

- グラデーションの飾り、飾りとしての英語大文字ラベル、絵文字のアイコン、意味のない番号（01 / 02 / 03）。
- 極端に大きく太い見出し。
- 太い枠線、原色の組み合わせ、強いドロップシャドウ。
