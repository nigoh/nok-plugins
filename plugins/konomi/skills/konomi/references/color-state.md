# 色と状況の理論

業務の状況（下書き・送付済み・期限超過…）を、どの色・絵・言葉で、どれだけ静かに見せるか。藍の使いどころ、ライトとダークの対、図の色もここで決める。

読む工程：ビジュアル・UI 設計、操作と言葉、実装（札・知らせ・図）。早見表は references/INDEX.md。
印：〔調査〕指針で確認／〔原理〕法則から導出／〔目安〕このスキルの値（実物で直す）／〔試作〕第3回の土台で決定。根拠・出どころ・検査（CK-01〜12）は records/sources.md・records/checks.md、設計書の書式は references/design-doc.md。〔目安〕の確かめていない物も records/sources.md。

理由は `C-02：期限超過・支払期限が過ぎて未入金・督促を決めるのは人 → wait（手の絵）` の形で 1 行残す。好みと食い違えば CP-1・CP-2 に反しない範囲で好み（色の値は taste.md が正）。

## 原理

| ID | 原理 |
| --- | --- |
| CP-1 | 色だけで伝えない（WCAG 1.4.1）〔調査〕 |
| CP-2 | 文字は 4.5:1、文字以外の目印は 3:1。押せない部品は対象外（1.4.3・1.4.11）〔調査〕 |
| CP-3 | 種類は少なく、同じ物は同じ色（GOV.UK・スコットランド政府）〔調査〕 |
| CP-4 | 印は控えめに。必要・期待・見落とすときだけ（NN/g）〔調査〕。目立つのは少数だけ〔原理〕 |
| CP-5 | 1 つの色に意味は 1 つ〔原理〕 |
| CP-6 | 色の意味は人・文化で違う。日本では信号の「青」は緑、赤字は損失〔原理〕 |
| CP-7 | 状況は「次に誰が何をするか」で分ける〔原理〕 |
| CP-8 | 強弱は位置・太さ・余白が先、色は最後〔原理〕 |

## C-01 調子の数

根拠：CP-3・CP-4・CP-7。問い：状況をいくつの調子に寄せるか。足してよいか。軸：状況の言葉の数／次の行動の主が違う組の数

| 条件 | 決め方 |
| --- | --- |
| 状況の言葉が 7 個以上 | 調子は 6 つまで〔目安〕：人の確認待ち wait／作業中 progress／失敗 fail／完了 done／一区切り calm／始まっていない draft。言葉は増やしても調子は増やさない〔試作〕 |
| 新しい調子を足したい | 「次の行動の主が違う」ときだけ。程度の違い（とても遅れている）では足さない。足すなら絵も新しく〔調査〕 |
| 1 画面で同時に見える調子 | 4 種まで〔目安〕。超えるなら「今日やること」の一覧に分ける |

## C-02 状況を調子に寄せる軸

根拠：CP-1・CP-4・CP-5・CP-7。軸：①次の行動を動詞で言えるか ②待つのは外の日付・相手か自分の都合か ③進み具合（未開始／進行中／終了／停止）

| 条件 | 選ぶもの |
| --- | --- |
| 未開始。次の行動（送る）はあるが外の日付も相手も待たない | draft（quiet・鉛筆）。完了の check にしない。急かさない〔試作〕 |
| 進行中で人は待つだけ（返事、入金） | progress |
| 外の日付か相手が待ち、人が判断する（期限超過、未確認、差額あり） | wait（warn・手）〔試作〕 |
| 処理の失敗、取り返しのつかない結果 | fail（bad）。期限超過は督促で取り返せるので fail にしない |
| 終わって成果がある（入金済み、確認済み） | done |
| 終わったが成果でない・人がもう何もできない（取り消し済み、有効期間切れ） | calm |
| 遅れ・停止だが人は何もしなくてよい | calm に時計の絵と「遅れています」 |

- **支払期限を過ぎた未入金は期限超過＝wait。「期限切れ」ではない**（期限切れ＝有効期間が消えた＝calm。同じ言葉にしない。`session_expired` は別物で調子に寄せない、E-02）〔試作〕。
- 支払期限は取引先ごとに違う。期限の日付で決め、取引先ごとに色を変えない。

## C-03 時間で変わる状況と、変わる流れ

根拠：CP-1・CP-3・CP-4・CP-8。問い：日付から計算する状況と、下書き→送付済み→入金済みの流れをどう見せるか。

| 条件 | 決め方 |
| --- | --- |
| 計算で決まる状況（送付済みで支払期限が今日より前） | 計算した状況の札だけを出す（送付済みの札と並べない）。「今日」は 1 か所で決める〔試作〕 |
| 期限の前 | 札は変えない。期限の列に「あと3日」と言葉で足す（G-07） |
| 超過の日数が増える | 調子を上げない（bad にしない）。「12日超過」と数字で言う（G-07） |
| 流れ 3〜5 段〔目安〕 | いまの段＝藍の塗りの丸＋太字＋「いま」、終わった段＝チェック、これから＝枠だけの丸と muted。つなぎ線は終わった間が実線、これからが破線 |
| 状況が変わった | 札は即時に切り替え、変わった行を 1 回薄く色づける（motion.md A-04）。短い知らせでも言う |

## C-04 色以外の手がかり、回る絵

根拠：CP-1・CP-2・CP-4・CP-6。問い：色に何を添えるか。回る絵を使ってよいか。

| 場面 | 添えるもの |
| --- | --- |
| 状況の札 | 絵＋言葉。**調子ごとに絵は 1 つずつ別**。言葉は体言止めか「〜済み」「〜あり」で 3〜6 字〔目安〕〔試作〕 |
| 回る絵 | **札・表・一覧の行の中では回さない**（札は止めた絵）。回してよいのは押して処理中のボタンと、読み込み中の待ちの印 1 画面 1 つ。動きを減らす設定で止める（motion.md A-03） |
| 選択中 | 地＋1px の線＋チェックの絵か `aria-selected` |
| 数の増減 | 色でなく符号と比べる相手の言葉（G-03） |
| 図の系列 | 直接ラベル、線の種類、印（C-11） |

調子ごとの絵と色の組（taste.md から移した。これが正）。アイコンは Lucide。形と言葉を必ず添える。

| 調子 | アイコン | 色 |
| --- | --- | --- |
| 始まっていない（draft） | `pencil` | quiet / quiet-text |
| 人の確認待ち（期限超過を含む） | `hand` | warn-soft / warn-text |
| 作業中 | `refresh-cw`（札の中では止めた絵） | ai-soft / ai-text |
| 失敗 | `circle-x` | bad-soft / bad-text |
| 完了 | `circle-check` | ok-soft / ok-text |
| 一区切り・遅れ | `circle-minus`（完了と別の絵）・`clock` | quiet / quiet-text |

- グレースケールでも札どうしが区別できること。数字は半角（「3日超過」）。

## C-05 藍を使う所・使わない所、面積

根拠：CP-4・CP-5・CP-8・D-04。問い：この要素を藍にしてよいか。面積はどこまでか。軸：操作か現在地か選択か／塗り・地・文字や線／画面の藍の数

| 条件 | 決め方 |
| --- | --- |
| 主ボタン | `ai` の塗り。1 画面に 1 つ。主操作が無い画面は塗りを置かない |
| リンク、現在地、選択中、フォーカスの輪、案内の知らせ、進行中の札 | 文字・線・`ai-soft` の地まで。塗りにしない |
| 見出し、本文、数字、表の行の地、全面の帯 | 藍にしない（`fg`） |
| `ai-soft` が重なる（選択中・進行中の札・案内の知らせ・現在地） | 形で分ける。札＝線なし・角 6・絵が先頭。選択中＝1px の線。知らせ＝幅いっぱい・角 12。現在地＝太字。藍の下地の上の札は地を外し、絵と言葉だけにする〔試作〕 |
| 面積 | 画面のうち `ai` の塗りは 3% 以下、白・灰・線・文字以外の色の地（藍の下地と意味の色の下地の合計）は 10% 以下〔目安〕 |

## C-06 意味の色と状況の色、数字の色

根拠：CP-5・CP-6・CP-8・好み。問い：緑・赤・黄の意味と状況の調子が同じ色のとき、どう分けるか。数字に色を付けてよいか。

| 条件 | 決め方 |
| --- | --- |
| 色の意味 | ok＝終わった・できた／warn＝人が判断する／bad＝失敗・取り返しがつかない・消す／ai＝操作・選択・現在地・進行／quiet＝急がない。1 色に 1 つ |
| 金額・件数・比率の数字 | 色を付けない（`fg`、補足は `muted`）。色は札と知らせだけ |
| 増減（売上、未入金） | 良し悪しで塗らない（未入金が増えるのは悪く、売上が増えるのは良い。同じ「増」が逆になる）。形と比べる相手の言葉は G-03 |
| マイナスの金額 | 赤にしない（`fg`）。書式は G-05（「−12,000円」） |

## C-07 札・知らせ・行の強調・数字の使い分け

根拠：CP-3・CP-4・CP-8・D-11。問い：状況を伝えたい。札か、知らせか、行の強調か。軸：1 件か画面全体か／いますぐ動くか

| 条件 | 選ぶもの |
| --- | --- |
| 1 件ごとの現在の状況 | 札。1 件に 1 つ（調子の違う札を並べない） |
| 画面全体で、人が先にすること | 知らせ。先頭に。1 画面に 2 つまで〔目安〕。3 つ以上なら「今日やること」の一覧（件数つき）へ |
| 一覧で見つけさせたい行 | 行の地を塗らない（選択中と衝突）。並びの先頭に出し、札で示す。左端に色の太線を引かない |
| 取り返しのつかない失敗 | fail の知らせ（`role=alert`）。閉じるまで残し、置き場所は E-06。すぐ消える短い知らせにしない〔調査〕 |

## C-08 同じ札が何十も並ぶときの静かさ

根拠：CP-3・CP-4。問い：札が何十個も並ぶとき、全部に地と色を付けるか。軸：見える札の数 N／多数派の調子／絞り込み中か

| 条件 | 決め方 |
| --- | --- |
| N が 5 以下 | 通常の札（地・絵・言葉） |
| N が 6〜9 | 通常の札。太字は wait と fail だけ、ほかは太さ 400〔目安〕 |
| N が 10 以上 | wait と fail は通常の札。progress・done・calm・draft は「静かな札」（地なし、絵と言葉、文字は `*-text` か `muted`）〔目安〕 |
| 札が 6 枚以上で、1 つの調子が 80% 以上 | 多数派を静かな札に、少数派だけ通常の札で目立たせる。5 枚以下では 80% を数えない（4 枚中 4 枚が同じでも通常の札）〔目安〕〔試作〕 |
| 状況 1 つで絞り込み中 | 全行が同じ。状況の列を外すか全部を静かな札に（条件は見えている） |

- 静かな札でも絵と言葉は消さない。目立たせる色は、一覧ではなく先頭の「今日やること」に集める。

## C-09 押せない・読み取り専用・選択中・現在地

根拠：CP-1・CP-2・V-12。

| 状態 | 見せ方 |
| --- | --- |
| 押せない | `disabled-bg`・`disabled-fg` で薄く。**理由を近くに文で**（薄くしない）。処理中は薄くせず、処理中の言葉と絵 |
| 読み取り専用（取り消し済みの請求書） | 入力欄の形にしない。ラベルと値を `fg` の文字で並べ、先頭で「取り消し済みです。変更できません」と 1 度言う |
| 選択中 | `ai-soft`＋1px の `ai` の線＋絵か `aria-selected`。線は地に 3:1 以上（実測 10.5・8.2〔試作〕）〔調査〕 |
| 現在地 | `aria-current`＋`ai-soft`＋太字。押せるままにする |

## C-10 ライトとダークの対、コントラストの線

根拠：CP-2・CP-8。

| 条件 | 決め方 |
| --- | --- |
| 作り方 | 役の名前は同じで値だけ変える。暗は反転せず、明るさを上げて彩度を落とす（藍 `#1f3f6e`→`#8fb0e6`）。暗の地は純黒にしない〔目安〕。明るい画面の白地は好みで決定済み。影は暗では面の明るさの差に替える |
| 文字と地 | 4.5:1 以上。大きな文字（18pt＝24px 以上、太字は 14pt＝約19px 以上）は 3:1〔調査〕。札の 14px 太字は大きな文字ではない |
| 線・絵・選択の目印・入力欄の枠 | 地に対して 3:1 以上。押せない部品は免除〔調査〕 |
| 余裕 | 文字は 5.0:1 以上で置く〔目安〕。`line-strong` は明るい 3.04:1（余裕 0.04。動かすなら先に測る）、暗い 4.31:1。`disabled-fg` は 2.66（免除）〔試作〕 |
| 更新中に前の内容を薄くする | 文字の不透明度を下げない（文字が 4.5:1 を割る）。薄くするのは地か、上に重ねる膜。膜を重ねた後の文字と地も 4.5:1 以上で測る。薄くしても「更新しています」の文は通常の濃さ（E-04）〔原理〕 |
| 確かめ方 | 札の `*-text` と `*-soft` は実測 5.87〜8.70。soft の地そのものは白地に 1.1〜1.2 でよい（意味は絵と言葉が運ぶ）。全部の組を明暗で計算し、片方だけ直さない。切り替えは OS の設定に従う〔試作〕 |

## C-11 図の系列の色

根拠：CP-1・CP-3・CP-4・CP-5。問い：図の系列にどの色を当てるか。軸：系列の数／系列が「状況」か取引先・月か／直接ラベルを置けるか。系列の数とまとめ方は G-09 が正（5 つ以上は上位 4＋「その他」）。

| 条件 | 決め方 |
| --- | --- |
| 1〜2 系列 | 主を藍、比べる相手を灰（`line-strong`）。線なら実線と破線 |
| 3〜5 系列〔目安〕（「その他」を含む） | 藍の濃淡と灰＋直接ラベル、線種か印（○□△）。色だけで区別しない。「その他」は灰 |
| 6 系列以上 | 作らない。G-09 でまとめる（デジタル庁の例も 10 色の枠〔調査〕） |
| 系列が状況 | 札と同じ調子の色・同じ絵 |
| 系列が取引先・月・品目 | 状況の色（緑・黄・赤）を使わない |
