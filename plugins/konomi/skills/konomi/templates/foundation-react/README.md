# 土台に最初から入れる物

試作第3回（土台 1 人＋画面 10 人）で、合流のあとに土台へ引き上げた物の一覧。**コードはここに置かない**（製品のリポジトリの側に置く）。決まりは references/teamwork.md の B-01（最初から土台に入れる物）と B-06（機械の番人）。

| 物 | 何を防ぐか（第3回で起きたこと） |
| --- | --- |
| 番人（構造）：層・直書き・余白・時間・`?? 0`・Intl・S-10 の order・placeholder／type=number・isComposing | 層の逆向き、色や px の直書き、画面が履歴を直接さわる、同じフックの自作 |
| 番人（文言） | 避ける語、設計の言葉の漏れ、共通の語の直書き、「…」「！」 |
| 移動と URL（nav） | 履歴を積まない移動を 6 画面が自作した |
| 離れる時の確かめ（useLeaveGuard・LeaveDialog） | 3 画面が別々に作り、戻るボタンの言い方が 3 通りになった |
| 更新中・古い内容（StaleNotice） | 文が 4 通りになった |
| 数・日付の整形（format） | 「6月月」。月の名前を作る所が 2 つあった |
| 入力の読み（normalize） | 全角→半角・日付・金額の読みを 5 画面が別々に作った |
| ページ送り（paginate） | 件数の定数を 5 回定義した |
| 偽の取得と保存（useFake・fakeSave） | 待ち時間がばらばら、保存の失敗を画面で出せなかった |
| トークンの対応（index.css） | Tailwind の語彙を役の名前だけにしぼる |

番人は土台と同時に用意する。合流の途中は「いまの違反は一覧に出すだけ、新しい違反だけ落とす」形にし、置き換えが済んだら全部落とす形に切り替える。手引きの型は `templates/guide-for-screens.md`。
