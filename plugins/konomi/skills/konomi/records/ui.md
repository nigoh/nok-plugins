# UI/UX アンチパターン集

計画の点検と仕上げの点検で使う。全部を一度に読まず、作っている画面に関係するカテゴリだけを開く。

- **検出**の読み方：`自動` は計算済みスタイル・静的解析・axe などで実際に測る。`半自動` はスクリーンショットや文言を見て一次判定する。`目視` は人が判断するので、判定せずに確認依頼として伝える。
- 「要確認」と書かれた数値・規格・法令は、使う前に一次情報で確かめる。
- C1（ダークパターン）は点検項目ではなく禁止事項。頼まれても作らない。
- 好み（DESIGN.md）と衝突する項目は好みを優先する。ただし MUST（コントラスト、タップ領域、状態定義、lang）は好みより優先する。
