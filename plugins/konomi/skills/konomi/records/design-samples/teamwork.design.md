# teamwork.md から移した節（design）

## 設計段階で示す物

### 1. 手引きの型

```
# 画面を作る人への手引き（つづり請求）
## 0. 先に読む物（土台の完了点＝<版>）
## 1. やってはいけないこと（✓＝機械が止める）
## 2. 画面ファイルの形
## 3. 使える部品（入口ごと）
## 4. 使い方の決まり
## 5. 状態の切り替え方
## 6. テストの付け方
## 7. 報告のしかた
## 8. 迷ったら
```

### 2. 土台の完了条件の点検表

全行が合格になるまで画面を始めない。

| 項目 | 合格の線 | 確かめ方 |
| --- | --- | --- |
| 骨格 | `shell` にメニュー・主操作・戻り方があり、見本が動く | 人 |
| 呼び名 | `terms` に使う語と避ける語が対で 20 組以上〔目安〕 | BT-06 |
| 状態表 | 全画面に状態があり、画面固有の語彙が足りる | 照合 |
| 部品・見本データ | 手引きの一覧と実物が一致。見本が全状態で動く。固定の「いま」がある | 半自動 |
| 番人・完了点 | BT-01・03・06・07 が入り、悪い例で落ちる。土台の版（タグ）を打った | 自動＋人 |
| 手引き | 9 見出しが埋まっている | 半自動 |
| 標準セット | B-01 の「最初から土台に入れる物」が入っている | 半自動 |
