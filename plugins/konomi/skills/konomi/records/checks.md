### ui-audit.py

```
"""konomi ui-audit
画面（HTML）を全状態で開き、機械で測れる項目を確かめて evidence/ui-report.json に書く。
人やエージェントはこのレポートを書かない・直さない。

使い方:
  python3 ui-audit.py <リポジトリのルート> <画面の HTML か、それが入ったフォルダ>...
  python3 ui-audit.py <リポジトリのルート> --spa <1 枚に固めたアプリの index.html>   （?screen=<slug>&state=<状態> で画面を選べること）
オプション:
  --only <slug>[,<slug>]   指定した画面だけ点検する（並行作業用。他人の未完成の画面を巻き込まない）。slug は --spa なら ?screen= の値、HTML なら拡張子なしのファイル名。
  --out <フォルダ>         evidence の出し先（既定は <ルート>/evidence）。ui-report.json と shots/ がここに出る。並行して走らせるときは別々のフォルダにする。
                           <ルート> にアプリ本体を指すと既定では evidence/ を上書きするので、写しの置き場を --out に指すか、ルートを別フォルダにして
                           node_modules と .konomi を symlink する。
  --standalone             上のメニューの共通性（shell-nav）を見ない。
必要なもの: Python の playwright、Chrome。axe-core は <ルート>/node_modules/axe-core にあれば使う（無ければ not_run）。
状態は、data-scr を持つ要素の data-states="default,empty,..." から読む。無ければ default だけ。
共通の骨格と呼び名は <ルート>/.konomi/screens.yaml の shell.nav と terms から読む（PyYAML があれば）。
  terms の各行に allow: ["適格請求書発行事業者"] を書くと、その語の中に含まれる avoid の語は数えない（制度が名前を決めている語）。
点検の約束（誤検出を避けるため）:
  * 窓（dialog[open]・[role=dialog][aria-modal=true]）が開いている間、当たり判定（hit-area-44）と A-01 は窓の中だけを見る。窓の裏・inert・aria-hidden の祖先を持つ要素は数えない。
  * shell-nav は、複数の nav のうち shell.nav の語を最も多く含む 1 つだけを見る（画面の中の関連リンクの nav は数えない）。
  * states-distinct は、文字数でなく表示の文字そのもの＋DOM の要約（窓・disabled・aria-busy・invalid・alert の数）の指紋で比べる。
  * axe-serious は規則ごとに、代表の selector と色（前景・背景・比）を 3 件まで detail に出す。
  * WORDS-dup：数字の直後の単位の重なり（6月月・12件件）と、数字が無くても 月月・年年・円円・件件・％％（今月月末・毎年年初のような正しい語は除く）。日日 は数字の直後だけ見る。
  * fixed-band-last-item：375px で最下部までスクロールし、下に固定した帯が最後の押せる要素・最後の文を隠していないか。
"""
```
