# skill-distiller

上位モデル（Sonnet）の解き方を、重みに触れずスキル1枚にまとめて下位モデル（Haiku）に移し、効果を測るプラグインです。

## 入れ方

```
/plugin marketplace add nigoh/nok-plugins
/plugin install skill-distiller@nok-plugins
```

## できること

「スキルを蒸留して」「蒸留実験を回して」と頼むと、次を順に実行します。

1. 課題を蒸留用と検証用に分け、実行回数と費用の目安を示して確認を取る
2. 蒸留用を両モデルに解かせ、差があるかを確かめる（差が小さければここで止まる）
3. 両者の答案とメモの差分から、分析役が教訓を書き、スキルにまとめる
4. スキルが蒸留用で逆効果になっていないかを確かめる
5. 検証用で4条件（生徒のみ、教師のみ、生徒＋スキル、生徒＋プラセボ）を比べる
6. 正解率、差の縮小率、区間つきの判定をレポートにする

## 用意するもの

課題ファイル（JSON Lines）。1行に1課題で、問題文と正解を書きます。

```json
{"id": "q1", "prompt": "問題文", "answer": "正解"}
```

- 同じ種類の課題を60件以上（初期設定は蒸留用20件＋検証用40件）
- 自動で採点できる短い答え。複雑な採点は Python の採点関数を渡せます
- 正解は検証済みであること

## 構成

| 種類 | 名前 | 役割 |
| --- | --- | --- |
| スキル | distill-skill | 蒸留の手順全体 |
| エージェント | distill-student | 生徒役（Haiku、読み書きのみ） |
| エージェント | distill-teacher | 教師役（Sonnet、読み書きのみ） |
| エージェント | distill-analyst | 分析役（Sonnet、読み書きのみ） |

解答役のエージェントはファイルの読み書きしかできず、コードの実行やウェブ検索はできません。

## 費用の目安

初期設定で93実行です。1実行はサブエージェント1回で、およそ10万〜25万トークンかかります。開始前に必ず確認が入ります。

## 注意

- 教師と生徒の差が出ない課題では蒸留できません。仕様が明確な関数実装では Sonnet と Haiku に差が出ませんでした。
- 結果はその種類の課題に限ったものです。
- 正解ファイルは作業フォルダ内に置かれます。解答役には自分のシートの場所しか渡しませんが、技術的に読めない仕組みではありません。
- 実際のモデルを使った通し実行は、このプラグインの形ではまだ行っていません。スクリプトは模擬の解答者で検証済みで、手順は手作業で行った実験（チェスの2手詰め）と同じです。
