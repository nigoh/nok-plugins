# SCR-001 ホーム（slug：home）設計書

担当：ホーム。kind＝view。states＝default・loading・error・empty・todo_empty・many（screens.yaml のとおり。足さない・変えない）。
covers：REQ-001・002・003・006・007・008・010・012・027・028（010 と 028 は製品全体の要件で、ここでは「外部の読み込みが無い」「層の向きと直書き」を代表して確かめる）。
状態の確かめ方：`?screen=home&state=<名前>`。

## 1. この画面で人がすること

- 開いて、**今日まずやること**（期限超過の請求書、未確認の入金、下書き）と、**今月の数字**（請求額・未入金の額・期限超過の件数）を 1 度に確かめる。押すと該当の画面へ移る。
- 新しい請求書を作り始める（主ボタン「請求書を作る」）。
- 請求書が 1 件も無い初回は、作る導線と、はじめての設定への入口だけを見る。

**最初の 1 画面に置く物（D-14）**：主役は「今日やること」（この画面を開いた人が最初に決めるのは「何から手を付けるか」）。見出しの直後に件数つきで置く。
数字の主役は「今月の請求額」（display 28px、ほかの 2 つは title 22px：G-03）。
スマホ（375×812）の最初の 1 画面には、見出し・「今日やること」の 3 行・「請求と入金の状況」の見出しと先頭の数字の頭、下に固定した主ボタンが入る。説明文・知らせは置かない（題名→説明→知らせ→本体の定型にしない）。
REQ-012「今日やることが先頭」は、見出しの直後の先頭と読んだ。

## 2. 判断の記録

### 形・並べ方・文字（D-）

- D-01：区画 3 つ（今日やること・請求と入金の状況・最近の動き）、全員が全部読む・見比べる・順番は無い → タブにも畳みにもせず、縦に全部並べる。P-1・P-8
- D-02／D-03：入力欄・選択肢・数値の入力が 0 → 該当なし（この画面は入力しない。form.md は読まない）
- D-04：主ボタン「請求書を作る」1 つ（LinkButton、別の画面へ行く）。ほかの移動（行・リンク）は文字のリンク。絵だけのボタン 0・たまにしか使わない操作 0 → 「その他」は作らない。P-5・P-7
- D-05：ボタンは主 1 個・9 字以内・下に固定する帯も骨格が決める（768px 以上は見出しの右、未満は下に固定）。副は置かない → 並べ方の判断は骨格に任せる。空の表示の中は文字のリンクだけでボタンを重ねない
- D-06：文字の段は 4 つ：body 14（行の補足・比べる相手・札）／large 16 太字（区画の見出し・件数）／title 22（数字 2 つ）／display 28（今月の請求額 1 つ）。14→16 は 1.14、16→22 は 1.38、22→28 は 1.27 で、どれも 1.125 以上。small 12 は使わない（時刻・件数を 14 以上で読ませたい：判断に使う値は 12 にしない）
- D-07：区画の間は骨格が決める（スマホ 32・768px 以上 48）。区画の中は、見出しと中身の間 16、行の内側の上下 12、数字のかたまりの間 24（スマホ）／32（768px 以上）、名前と数字と比べる言葉の間 4。部品の内側＜仲間の間＜区画の間の順を逆にしない
- D-08：左端は 1 本（見出し・行・数字の頭が main の左端）。行の乗せたときの地だけ左右 12px はみ出す。数の列（件数）は右端に右揃え・等幅。数字 3 つは左揃え（並べるだけで列として比べないため）
- D-09：数字と単位（円・件）、日付は途中で折らない（nowrap）。取引先名は 60 字まで折り返して全部見せる（省略しない）。見出しは `text-wrap: balance`（全体の CSS）
- D-10：税込は数字の見出しに括弧で書く（数字のすぐ近く）。「最も古い支払期限」は行の 2 行目（行の中）。注記を離して置かない
- D-11：今日やること＝行のリスト（面にしない。見比べず、1 行ずつ押す）。最近の動き＝リスト。数字 3 つ＝同じ書式で並べた数字（G-01：値が 3 つで並べるだけ）。表は作らない
- D-12：図を作らない。G-01：数字 3 つと、比べる相手は先月の 1 つずつ（時間の点が 5 つ未満）なので図にしない。主張が無い数字の並びを図にしない
- D-13：幅の組み替えは中身で決めた。数字の最大（display の「99,999,999 円」≒ 170px）が 3 列で収まる最小の幅は 3×170＋間 64＝約 600px →「768px 以上は 3 列」。1024px 以上は骨格が左にメニューを出し、残り 800px 弱を「今日やること｜数字」の 2 列にする（数字は縦に 3 つ）。375px は全部 1 列。境目の前後（767/768、1023/1024）で崩れないか見る
- D-14：上の 1 を参照。「今日やること」が見出しの次。数字は 2 つ目

### 色と状況（C-）

- C-02：期限超過・支払期限を過ぎた未入金・督促を決めるのは人 → wait（手）。未確認の入金・自分が請求書を選ぶ → wait（手）。下書き・自分が送る・期限なし → draft（鉛筆）。土台の状況の表のとおりで、新しい調子は足さない
- C-07：画面全体で人が先にすること → 知らせでなく「今日やること」の一覧（件数つき）。知らせは default で 0 個。`todo_empty` だけ、結果を言う完了の知らせ（ok）1 つ
- C-08：見える札は 3 枚（5 枚以下）→ すべて通常の札。`tagDensityOf` に見えている調子を渡して決める（多いとき自動で静かになる）
- C-06：数字（金額・件数・比率）は fg、補足は muted。増減（+7,500円）も、未入金の増加も、良し悪しで塗らない。矢印の印は置かない（符号と「比べて」の言葉で足りる：C-04）
- C-05：藍は主ボタンの塗り 1 つ、リンクの文字。面積は塗りが 3% 以下
- G-03 の「基準があるとき警告の札を数字の隣に」：期限超過の件数は基準（支払期限）がある数字だが、同じ画面の「今日やること」の先頭の行に札つきで出ているので、数字の隣には札を足さない（同じ警告を 2 回出さない：CP-4）
- 色の予算：`SCR-001 ホーム：主ボタン 1・藍の塗り 1・札の調子 2 種（wait・draft）・札 3 枚→通常の札・知らせ 0（todo_empty のとき ok 1）・数字の色すべて fg／muted・回る絵 0（error の再試行を押した間だけボタン内に 1）`

### 入れ子と順序の確認（S-01・S-10）

- 押せるものの中に押せるものを置かない：行（Link）の中は文字・札（span）・絵だけ。ボタン・別のリンクを入れない。Notice の中のリンクは Notice の action の口（兄弟）。

- 見た目の順＝DOM の順：todo → 数字 → 動き。1024px の 2 列は格子の自動配置（左→右、上→下）で、`order`・`reverse`・列指定を使わない。主ボタンは骨格（見出しの右／スマホは下に固定、DOM の最後）。
- 同じ id を 2 つ作らない：見出しの id は 3 つ（固定）、`aria-labelledby` で区画に結ぶ。

## 4. 動きの仕様（motion.md A-08）

この画面が新しく足す動きは「行の乗せたとき・押したときの地の色」だけ。残りは基本の部品が持つ動き。

| 物 | 役 | 時間 | イージング | reduced-motion |
| --- | --- | --- | --- | --- |
| 行（今日やること・最近の動き）：乗せたとき地を 1 段（col）、押したときもう 1 段（line） | 応答・手がかり | `--dur-instant` | 標準（色の変化のみ） | 色の変化は残す（情報を運ぶ小さな変化） |
| 主ボタン「請求書を作る」：乗せた・押した・キーボード | 応答 | 押した `--dur-instant`、戻り `--dur-quick`（Button の既存） | `--ease-move`（既存） | 縮みは止め、色は残す（既存） |
| 骨組み（loading） | 待ち | 0.3 秒たってから現れる `--delay-wait`＋`--dur-instant` | `--ease-enter`（既存） | 現れるだけ。動かさない |
| もう一度読み込む（error）：押したボタンだけ処理中 | 待ち | 回る印 `--dur-spin`（Button の既存。画面で 1 つまで） | linear（既存） | 止まる（既存） |
| 行の絵（›） | 手がかり | 動かさない | — | — |

動かさないと決めたもの（A-05）：
- 数字（数え上げの動き）：G-03 のとおり付けない。開くたびに見る数字を毎回動かさない（N-8）。
- 画面を開いたときの区画の浮かび上がり：付けない（A-04：開いたとき動かしてよいのは主役 1 つまで。主役は数字と行で、静かさを優先）。
- 「片付いた」知らせの出現：付けない。印になる動き（A-06）は共通の既定に置かないので、この画面でも置かない。
- 区画の入れ替え（loading → 本体）：濃さの切り替えだけにせず、即時（1 日に何度も開く画面：N-8）。

## 5. 実装で変えたこと

- 読み込み中の見た目：区画の見出しは読める状態のまま残し、中身の枠だけを隠す（見出しまで隠すと読み込み中の画面で何の画面か分からなくなるため）。
- 最近の動きの一覧：1024px 未満では今日やることの一覧と幅をそろえ、lg 以上では `lg:max-w-2xl` で行が伸びすぎないようにした。
- 空の画面の文：後半を折り返さない塊にして、途中で切れないようにした。始め方は押すボタンではなく「はじめの設定」への文中リンクにした。
- 長い取引先名の見本は 60 文字に固定した。
- 最近の動きは未来の時刻を含めない。入金の出来事には時刻がないため日付だけで並べる。
- 今日やることの名詞は用語表の請求書の名前をそのまま使い、直書きしない。
- 見本の用意は状態ごとに 1 回だけにした（useFake の作る関数は描画のたびに呼ばれるため）。
- 画面内の小部品には部品番号（data-cmp）を付けていない。
