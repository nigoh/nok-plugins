## 1. この画面で人がすること、最初の 1 画面
- 期間（半年・1年・今年度）を選び、月ごとの請求額と入金額（図と表）、取引先別の内訳（棒と表）を見る。
- 「表を書き出す」で、いま見ている期間の 2 つの表を 1 つのファイルにする。請求書の一覧・取引先の一覧へ移る。
- 最初の 1 画面（375×812）：見出し → 期間 → 月ごとの題・期間の 1 行・要約 1 文 → 図の頭（図の位置 518px）。主役は図。主ボタンは下に固定。

## 3. 判断の記録
- D-01：期間 3 つ・同格・最長 3 字・同時に見るのは 1 つ → セグメント（3 つ合わせて約 200px ＜ 343px）。URL の `period` に持ち、切り替えは履歴に積まない（REQ-027）。既定の半年は URL に書かない。
- D-04：主ボタン 1 つ「表を書き出す」（7 字）・見る画面 → 見出しの右（768px 以上）、未満は下に固定。`empty` だけは同じ位置が「請求書を作る」
- D-06：文字の段が 3 つ［14・16・22］（ui-audit で測定）・新しい大きさの要る見せ物が無い → 段を増やさない
- D-09：取引先名の最長 60 字・35 社 → 折り返して全部見せる（棒は文字を HTML、棒だけ SVG）。数字と単位は折らない。
- D-11：月ごと 3 列・取引先別 4 列で数を見比べる → 表（DataTable）。図の直下に常に置く。
- D-12：図は見出し・期間の行・要約 1 文の次。系列 2＋「途中の月」の 3 つは直接ラベルを置けない（1 か月 24〜64px）→ 図に接した凡例 1 行。
- D-13：図は実寸（1 目盛り＝1px）で描き縮めない。375px・12 か月で 1 か月 24px ＜ 40px → 月の名前は 1 つおき、最初と最後は出す（G-08）。
- C-05：藍の塗りに当てる物が主ボタン 1 つと請求額の棒（2 系列の主）、入金額は比べる相手 → 入金額は灰（`line-strong`）、ほかは文字・線まで
- C-06：金額・件数・割合の数字・比べる相手は図の中の入金額 1 つ → 数字は `fg`、補足は `muted`。増減の色は付けない
- C-10：更新中に前の内容を薄くしていた（opacity-60。例 4.24:1 ＜ 4.5:1、167 か所）→ 薄くしない。更新中の印は「更新しています」の文・押せない部品・`aria-busy`。ui-audit の color-contrast 0。
- C-11：2 系列（請求額・入金額）→ 藍と灰、当月は斜線。取引先の棒は藍、「その他」は灰。状況の色は使わない。
- E-04：`refreshing`・`stale` は前のデータがある → 前の図と表を残し、止めるのは期間・ページ送り・書き出しだけ（`stale` は書き出しだけ）。理由は「更新しています。この間は、期間を変えることも、表を書き出すこともできません」を期間と書き出しに `aria-describedby` で結ぶ
- E-05：初回の 0 件 → 説明 1 文と文中リンク。主と同名のボタンを重ねない（決定 9）。期間の 0 件は `filtered_empty`（期間も条件）。
- E-06：一部の月が取れない（見本は 2 か月）→ 図の上の知らせ（warn）に月名と理由と再試行。合計は「取れた4か月ぶん」。取れた分は残す。
- G-01：月ごとの点 6〜12・形が主役 → 縦棒の図と表。取引先 13〜35 行・1 円まで照らす → 表（棒は上位だけ）。
- G-02：各点が「その月の合計」・6〜12 点 → 縦棒（0 始まり）、2 系列は並べる。取引先 13〜35 社・名前が全角 60 字 → 横棒、多い順。
- G-05：図の目盛りの最大 1,413,500 円（≥ 1,000,000）→ 万円、題に 1 回（「月ごとの請求額と入金額（万円）」）、目盛り 4 本（0・50・100・150）。表は 1 円まで・桁区切り・見出しに「（円）」。
- G-06：取れない月 → 「—」（図は棒なし、読み上げは「データなし」）。計算して 0 → 「0」と高さ 0。当月 → 「11月（途中）」と斜線。欠けを 0 にしない（型は `number | null`）。
- G-07：期間が同じ年・年をまたぐ・今年度の 3 通り → 「2026年6月〜11月（6か月）」・「2025年12月〜2026年11月」・「2026年度（2026年4月〜2027年3月）のうち、2026年4月〜11月（8か月）」。月の名前は土台の `monthName` 1 か所（「6月月」を作らない）
- G-08：期間を替えると縦軸の上限が変わる（例：150万円から別の値へ）→ 「縦軸の上限が150万円から…に変わりました」と 1 文。棒は 0 始まり
- G-09：取引先が 11 社以上 → 上位 10＋「その他（N社）」。「その他」が 1 位より大きければ上位 7（1年・14 社で 7＋その他 7 社）。図は上位だけ、表は全件。
- G-10：図・表・取引先・書き出しの 4 つが期間に従う・当月（11月）を含む → 全部が同じ期間、題の下に常に期間の行、当月は「途中」
- G-11：取引先別の表は REQ-023「内訳の表を必ず見せる」が正 → 13〜35 行でも畳まず常に見せる（理論の例外）。20 行超（many・35 行）はページ送り 2 ページ、合計は全件を表の上に。月ごとの表は 6〜12 行 → 常に見せる。図は `role="img"` で要約と同じ名前。
- G-12：書き出しの元が画面の数と同じでなければならない（GP-7）→ 同じ集計関数（`aggregate.ts`）から月ごとと取引先別の 2 表を 1 ファイルに。数は円・桁区切りなし、欠損は空欄、当月は「途中」、BOM つき UTF-8。名前 `つづり請求_売上レポート_2026-06_2026-11.csv`
- L-07：0 件が 2 種類（初回・期間の 0 件）→ 初回は説明と次の一手の文、期間の 0 件は条件を言う文（「条件に合う請求書はありません」）
- L-08：待ちの文は 20 字以内が型・最長「書き出しています」7 字 → 「〜しています」。共通の文は terms から引く
- A-05：期間の切り替え・ページ送りは 1 日に何度も行う → 動かさない。新しい動き 0。

## 9. 実装で変えたこと（第 2 段の置き換え 8 件）
- URL の値：自作の `useUrlParam.ts`（20 行）を消し、`app/nav` の `useUrlParam('period', 'half')`・`useUrlParam('page', '1')`＋`paramNumber`。期間を替えたらページを 1 に戻すのは `replaceParams` で 1 度に。
- ページ送り：`PAGE_SIZE` の定義を消し、`paginate`・`Pagination`（件数を渡さない）。更新中はページ送りも止める（これまで止めていなかった）。
- 更新中・古い内容：`StaleNotice`（子に `span#exportNoteId`）・`RefreshingNote`。止める理由を期間と書き出しの両方に結んだ（これまで理由が無かった）。
- 押せない：期間は `Segmented disabled`（`fieldset disabled` をやめた）。更新中の文字の不透明度を下げない（C-10。不具合の直し）。
- 月の名前：土台の `monthName` が「6月」を返すので画面は変えず、「月月」が出ないテストを足した。
- 見本：取引先の割り当て以外は `manyInvoices()`。0 件の主と同名のボタンを文中リンクに（決定 9）。
- 文言ファイルを `texts.ts` から `copy.ts` に。行数（テスト除く）890 → 881（消したファイル 1＝20 行）。
- 土台に足りない物：`save_failed` が report の states に無いため、書き出しの失敗に状態名が無い。読むだけの取得の自動再試行（`autoRetry`）は置き換え表に無く、使っていない。
