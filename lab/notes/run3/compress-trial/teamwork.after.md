## B-01 先に決める物と任せる物

根拠：BP-1・BP-2・BP-4。軸：①2 画面以上に出るか ②画面が違っても同じであるべきか

| 条件 | 決め方 |
| --- | --- |
| 全画面に同じ形で出る（メニュー、主操作の位置、戻り方） | 先に決める。`shell` に書く（W-29） |
| 呼び名、文の調子（です・ます）、避ける言い方、円と日付の書き方 | 先に決める。`terms` に使う語と避ける語を対で〔試作〕 |
| 画面の一覧、各画面の状態（固有も）、受け持つ要件 | 先に決める。担当は状態を足さない（W-07）〔試作〕 |
| 2 画面以上で使う部品・トークン・見本データ・状況→札の対応 | 先に作る。画面側で作らせない（S-04） |
| 画面をまたぐ窓（離れる窓・確かめの窓） | 1 度に決める（文言・ボタンの順・戻りの名前。戻りは「入力に戻る」）〔試作〕 |
| 1 画面の中だけの組み合わせ・並べ方・説明文・入力規則 | 各自に任せる |
| **最初から土台に入れる物**（入力画面・一覧の標準セット） | `useLeaveGuard`＋離れる窓、`nav.replace`、`useUrlParam`、全角→半角の直し、`paginate` と「押せない」、`fakeSave`、`save_failed`、全部品の `disabled`・`aria-describedby`、更新中・古い内容の文〔試作〕 |
