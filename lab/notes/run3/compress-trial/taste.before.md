## 角・影

- 角丸は大きさに応じて変える。札 `radius-tag` 6、ボタン・入力 `radius-control` 8、カード・面 `radius-card` 12、大きな面 `radius-panel` 16、チップ `radius-chip` 999。カードの 12 は決定、ほかは仮。
- カードは線で囲まず、ふんわりした影で浮かせる。（決定）
  - `shadow-card`：明るい `0 4px 24px rgba(31, 35, 40, .06)`、暗い画面では影を使わず `panel` と `bg` の明るさの差で示す。（値は仮）
  - `shadow-lift`：明るい `0 12px 32px rgba(31, 35, 40, .16)`、暗い `0 12px 32px rgba(0, 0, 0, .55)`。引いている間のカード、窓、短い知らせだけ。
- カードにするのは「独立して選ぶ・動かす・開く 1 つの単位」だけ。一覧の行、業務画面の区画、フォームの節は面にせず、余白と区切り線で分ける。（試作で決定）
- 選んだ状態は `ai-soft` の地に 1px の `ai` の線。太い枠は使わない。（試作で決定）
- 全部のカードに同じ影を機械的に付けない。重なりの上下を示す必要がある所に使う。
- ボタンは高さを決めず、最小の高さと上下の余白で作る。文字が折り返したらボタンが縦に伸びる。（試作で決定）
  - スマホ幅：見た目の高さも 44px 以上。
  - パソコン幅の密度の高い画面：見た目は 36px でよい。当たり判定は 44px 以上にする（`::after` を `position:absolute; inset:-4px 0` で広げる）。
  - 一覧の行の中のリンクやアイコンのボタンも同じ。行全体を押せるようにするか、当たり判定を広げる。`input`（チェック・ラジオ・スイッチ）は `::after` を持てないので form.md F-12 の作り方にする。
