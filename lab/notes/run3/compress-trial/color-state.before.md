## C-02 状況を調子に寄せる軸

問い：下書き・期限超過・止まっているものを、どの調子にするか。
軸：①次の行動を動詞で言えるか（「督促を決める」）②待っているのは外の日付・相手か、自分の都合か ③進み具合（始まっていない／進行中／終わった／止まった）

| 条件 | 選ぶもの | 根拠 |
| --- | --- | --- |
| 始まっていない。次の行動（送る）はあるが、外の日付も相手も待っていない | draft（quiet・鉛筆）。完了の check にしない。急かさない | CP-7〔試作〕 |
| 進行中で、人は待つだけ（相手の返事、入金） | progress | CP-7 |
| 外の日付か相手が待ち、人が判断する（期限超過、未確認、差額あり） | wait（warn・手） | CP-7〔試作〕 |
| 処理の失敗、取り返しのつかない結果 | fail（bad）。期限超過は督促で取り返せるので fail にしない | CP-4 |
| 終わって成果がある（入金済み、確認済み） | done | CP-5 |
| 終わったが成果ではない・人がもう何もできない（取り消し済み、有効期間切れ） | calm | CP-4 |
| 遅れ・止まっているが人は何もしなくてよい | calm に時計の絵と「遅れています」 | CP-1 |

- **支払期限を過ぎた未入金は期限超過＝wait。「期限切れ」ではない。** 期限切れ（有効期間が消えた）は calm。2 つを同じ言葉にしない。〔試作〕画面の状態名 `session_expired`（ログインの時間切れ。states.md E-02）は別の物で、この札の調子には寄せない。
- 支払期限は取引先ごとに違う（月末締め翌月末払い等）。期限の日付で決め、取引先ごとに色を変えない。
