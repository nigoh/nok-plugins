## G-03 大きな数字（指標）

問い：「今月の請求額」「未入金」に何を添えるか。軸：①何を決める数字か ②比べる相手 ③良し悪しの基準が設定にあるか

| 条件 | 決め方 |
| --- | --- |
| 構成と大きさ | 名前 → 数字 → 比べる相手 1 つ。全桁（万円にしない）。主役 1 つだけ display、ほかは title。狭い幅で 1 行に収まらなければ縦に積む（D-05・D-14） |
| 比べる相手 | 月の途中は先月の「同じ日まで」と比べ、文字で書く（「先月の13日までと比べて」）。月全体と比べない。月が終わった・期間全体は直前の同じ長さ（季節の波が大きく 1 年ぶん以上あれば前年同月を足す） |
| 比べる相手のデータが無い・先月が 0 | % を出さない。「先月の記録がありません」「先月は0円」 |
| 残高（ある時点の量）と期間の数字（期間の合計）を並べて比べる | 種類が違うので差や率を出さない。各数字の名前に時点か期間を書く（「11月13日時点の未入金」「5月〜10月の請求額」）。同じ書式・同じ単位で、見出しと数字の位置をそろえて隣に置く。比べるのは同じ種類（残高どうし、期間の合計どうし）だけ〔原理〕 |
| 前月比 | 差と率を併記「+120,000円（+10%）」＋矢印の印。14px 以上、`muted`（判断に使う値は 12px にしない：D-06） |
| 良し悪しの色 | 数字そのものに色を付けない（`fg`、補足は `muted`。C-06）。基準が設定・契約にあるとき（例：期限を過ぎた請求書が 1 件以上）だけ、数字の隣に `warn` の札と言葉を添える。増減だけで `ok`・`bad` を付けない。未入金のように増えると悪い数字は、件数と最も古い期限を隣に書く（V-11） |

数え上げる動きは付けない。例：`G-03：ホームの「今月の請求額」・月の 13 日・先月の記録あり → 「先月の13日までと比べて +120,000円（+10%）」。数字に色なし`
