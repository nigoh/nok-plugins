## 良い行と形だけの行

| 良い行（人が計算し直せる） | 形だけの行（書き直す） |
| --- | --- |
| `D-02：8 字×14px＝112px＋32px、3 個で ≈254px ＜ 343px → セグメント` | `D-14：上の 1 のとおり` |
| `D-05：離れる窓・3 個・最長 7 字・内側 464px → 必要 378px で収まる → 横。375px は 343px で収まらない → 縦` | `E-02：状態名は screens.yaml のまま` |
| `C-05：藍は主ボタンの塗り 1 個、面積 0.4%（測った）→ 他は文字・線まで` | `C-05：面積は塗りが 3% 以下`（測っていない。数字が根拠でない） |

形だけの行の直し方は 3 つ。(a) 数字を測って事実に入れる、(b) 当てはまらないなら行ごと消す、(c) 別の節に同じ中身があるなら ID で指さず、その節に 1 度だけ書く。

## 機械が見る線（trace-check の設計書の検査）

| 検査 | 線 |
| --- | --- |
| DOC-SIZE | 本体 20KB 以内（`## 付録` 以降は数えない） |
| DOC-ARROW | `- D-05：` の形の判断の行のうち「→」を含む物が 80% 以上 |
| DOC-EMPTY | 「対象外」「のとおり」「無い」だけで済ませた判断の行が 0 |
| DOC-TRIED | 変更シナリオ表の `試した` 列が `済` の行が 2 件以上 |
| DOC-MISSING | 画面のコードがあるのに設計書が無い（警告） |

3 件以上の書き込みと、`見込み`・`実際` の中身は人が見る。機械が通っても、判断の行を人が計算し直せなければ未完了。
