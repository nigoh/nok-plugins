# つづり請求（試作 第3回）

小さな事業者（1〜10人）が、請求書を作り、送り、入金を確かめるための業務ツール。
使う人：経理を兼ねる店主・フリーランス・事務の担当。PC が主、外出先でスマホからも確かめる。
性格：静か。数字が主役。急かさない。

## 10 画面（SCR-ID と slug は固定）
| ID | slug | 呼び名 | 中身 |
|---|---|---|---|
| SCR-001 | home | ホーム | 今月の請求額・未入金・期限を過ぎた件数、今日やること、最近の動き |
| SCR-002 | invoices | 請求書 | 一覧。状況で絞る、探す、並べ替え。PC は表、スマホは行の形を変える |
| SCR-003 | invoice-new | 請求書の作成 | 取引先・明細行（追加/削除）・税・合計の自動計算・下書き保存・確かめてから発行 |
| SCR-004 | invoice-detail | 請求書の詳細 | 状況の流れ（下書き→送付済み→入金済み）、明細、履歴、送る・入金を記録・取り消す |
| SCR-005 | clients | 取引先 | 一覧。取引先ごとの未入金額。探す |
| SCR-006 | client-form | 取引先の登録 | 新規と編集。住所（郵便番号から補完）、締め日・支払期限、担当者 |
| SCR-007 | payments | 入金の確認 | 入金の明細と請求書を突き合わせる。候補の提示、手で選ぶ、差額がある時 |
| SCR-008 | report | 売上レポート | 月ごとの売上と入金の図、取引先別の内訳、期間の切り替え、書き出し |
| SCR-009 | settings | 設定 | 自社の情報、請求書の番号・税の端数、通知。区分の切り替え |
| SCR-010 | setup | はじめての設定 | 3 段階（自社の情報→請求の決まり→最初の取引先）。途中でやめても続きから |

## 技術
React 19 + TypeScript + Tailwind v4（トークンは src/index.css の @theme に対応済み）。1 枚の HTML に固める。
画面は `?screen=<slug>&state=<状態>` で選ぶ（src/app/Root.tsx）。画面は `src/screens/<slug>/index.tsx` が `export const screen: ScreenDef` を出すだけで登録される。
通信はしない。データは src/data/ の見本と、待ち・失敗を再現できる偽の取得。
